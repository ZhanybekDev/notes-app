## Findings by Dimension

### D5. Dead Code / Bloat

**C5 — план сохраняет парсер, у которого не остаётся ни одного потребителя.**

`app/telegram_link.py:97` — единственное производственное обращение к `parse_start_command`, и
находится оно внутри `handle_start_command`, который план удаляет. При этом план прямо велит:
«Keep `issue_link_code`, `unlink`, `parse_start_command`, `_now` and `_expired`», и отдельно
сохраняет его параметризованный тест.

Одновременно `bot_commands._parse` делает ту же работу в более общей форме — возвращает пару
`(команда, аргумент)` вместо одного аргумента `/start`. То есть после применения плана в кодовой
базе оказались бы два парсера, один из них недостижимый, — странный итог для изменения, чья
заявленная цель именно чистое разделение ответственностей.

**Fix applied:** `parse_start_command` и его тест удаляются; параметризованный набор перенесён на
`_parse` в `test_bot_commands.py`, расширен случаем другого регистра (`/START`) и возвращает пару.
Покрытие разбора не теряется.

### D2. Cross-Component Pipeline

**C4 — инструкция задачи 2 порождает дублирующуюся ветку.**

Задача 1 завершает `handle_update` так:

```python
    if command == "start":
        return BotReply(chat_id, _start(...))
    return BotReply(chat_id, _help(language))
```

Задача 2 говорит вставить новый блок «in place of the closing
`return BotReply(chat_id, _help(language))`», и этот блок сам начинается с `if command == "start":`.
Исполнитель, следующий букве, заменит только последнюю строку и получит две одинаковые ветки
подряд. Поведение не сломается — срабатывает первая, — но это мёртвый дубль, который не поймает ни
один линтер и заметит любой ревьюер.

**Fix applied:** формулировка заменена на «everything from `if command == "start":` to the end of
the function», с объяснением, почему замены одной строки недостаточно.

### D11. Output Verification

**M2 — `README.md` умалчивает о командах.**

Ничего ложного в нём не появляется, но раздел «Telegram reminders» описывает бота как канал

взаимодействует напрямую, это заметный пробел.

**Fix applied:** в задачу 4 добавлен абзац для README с перечислением команд; `README.md` включён
в финальный `git add`.

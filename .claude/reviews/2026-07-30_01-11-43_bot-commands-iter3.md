## Findings by Dimension

Все двенадцать чисты.

Один кандидат был отвергнут по evidence и заслуживает записи, потому что показывает границу
между дефектом и вкусом.

**Отвергнуто — «локальные копии хелперов вместо кросс-импорта».** План велит `test_bot_i18n`
завести собственные `make_user` и `start_update` вместо того, чтобы импортировать эквивалент из
`test_bot_commands`. Выглядит как размножение сущностей. Проверка:

```
test_reminders.py:11      def make_user(db, *, tz=..., reminder_time=..., enabled=..., chat_id=...)
test_worker_polling.py:54 def make_user(db, username="alice")
test_telegram_link.py:14  def make_user(db, username="alice")
test_bot_i18n.py:7        from tests.test_telegram_link import make_user, start_update
```

Три независимые версии с разными сигнатурами — каждому файлу нужна своя форма — против одного
кросс-импорта. Локальная копия и есть господствующая практика; импорт между тестовыми модулями
здесь исключение. Правка навязала бы мой вкус вместо исправления дефекта, поэтому не применена.
